# StatLab — CM32051 Exam Notes

A self-contained static website distilled from the supplied lecture/lab materials.

## Open
Open `index.html` in any recent browser. Navigate to `r-syntax.html` for the separate R reference and `practice.html` for representative exam questions.

No build tools, npm, or backend needed. The typefaces load from Google Fonts if online, but system fonts are used offline. Source content and scripts are bundled locally.

## Features
- 19 topic chapters spanning R, stats, graphics, SPSS and hypothesis tests
- One worked question per concept chapter, with a separate small practice set
- SPSS / RStudio interface schematics, chart illustrations and menu flows
- Full R syntax quick-reference, searchable by section
- Search and local study progress (browser localStorage)
- Responsive layout and locally functional navigation

## Note on materials
Contents preserve the key instructional themes of Lab Sheets 1–13 and the supplied model paper. The site does not contain all exercise solutions. Some code examples and statistical explanations clarify concepts beyond the exact lab wording; illustrative charts are schematics unless otherwise stated. Uploaded originals are not redistributed in the output.
